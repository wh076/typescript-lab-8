**Автор:** Трофимов Михаил Олегович, группа ФИТ-241

## Описание

Девять самостоятельных консольных задач по TypeScript. Компилятор `tsc` собирает исходные файлы из `src/` в JavaScript. Примеры запускаются в Node.js и выводят результаты в консоль.

Проверено на Node.js v26.13.1 LTS.

## Команды

Из корня репозитория выполнить установку зависимостей, проверку типов и сборку.

```bash
npm ci
npm run check
npm run build
```

## Задачи и запуск

| Файл | Задача | Команда | Ожидаемый результат |
| --- | --- | --- | --- |
| `src/task1.ts` | Функции и перегрузки | `node dist/task1.js` | `12.50`, `TypeScript`, `2026-01-15T10:00:00.000Z`. |
| `src/task2.ts` | Кортежи и enum | `node dist/task2.js` | Красный `[255, 0, 0]` — `#ff0000`, зелёный `[0, 255, 0]` — `#00ff00`, синий `[0, 0, 255]` — `#0000ff`. Канал `256` вызывает `RangeError`, сообщение выводится из `catch`. |
| `src/task3.ts` | Псевдонимы типов и функции-сторожи | `node dist/task3.js` | Для корректного UUID выводится профиль Анны. Для строки `invalid-id` и числа `42` выводится сообщение о некорректном ID. |
| `src/task4.ts` | Иммутабельные операции | `node dist/task4.js` | Добавление дописывает `ts`, повторное добавление `node` возвращает копию. Удаление всех `web` даёт `['node']`. Объединение даёт `['web', 'node', 'Web', 'ts']`. Исходные массивы сохраняют свои значения. |
| `src/task5.ts` | Pipeline и обобщения | `node dist/task5.js` | Один шаг возвращает `10`, два — `Число: 10`, три — `ЧИСЛО: 10`. Несовместимый вызов закомментирован. |
| `src/task6.ts` | Reduce | `node dist/task6.js` | Смешанный набор даёт `{ paid: 125, free: 50 }`, пустой массив — `{ paid: 0, free: 0 }`. |
| `src/task7.ts` | Разбиение массива | `node dist/task7.js` | Числа разбиваются на `[[1, 2], [3, 4], [5]]`, строки — на `[['a', 'b'], ['c', 'd']]`. Пустой массив даёт `[]`. Размер `0` вызывает `RangeError`, сообщение выводится из `catch`. |
| `src/task8.ts` | Интерфейсы и класс хранилища | `node dist/task8.js` | Книга создаётся, находится, обновляется и удаляется. Повторный ID вызывает `Error`, сообщение выводится из `catch`. После удаления поиск и обновление возвращают `undefined`, повторное удаление — `false`. |
| `src/task9.ts` | Условные и сопоставленные типы | `node dist/task9.js` | Все пять проверок `Object.isFrozen()` возвращают `true`. Присваивания полям и элементу массива закомментированы. |
